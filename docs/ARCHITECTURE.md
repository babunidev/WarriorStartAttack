# WarriorStartAttack — architecture

**Author:** Babuni.dev

WarriorStartAttack.lua uses a whitelist of internal spell-icon paths to recognize configured Warrior actions. It deliberately starts attacks before rage checks; Intimidating Shout stops attacks. The manifest loads this one Lua file.

Sources: README.md, addon TOC and Lua files. This documents observed code, not confirmed in-game behavior.
